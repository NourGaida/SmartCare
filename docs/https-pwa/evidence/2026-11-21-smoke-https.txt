# Evidence — HTTPS asset smoke test (2026-11-21)

> Superseded by `2026-11-21-root-mime-types.txt`. The `pass=39` run below predates the root HTML checks; it did not request `/`, `/frontoffice/index.html` or `/backoffice/index.html` and therefore missed the `text/html` MIME regression.

## Before fix (VERIFIED)

```text
Command: curl.exe --ssl-no-revoke -sS -D - -o NUL https://app.smartcare.local/definitely-missing-404.css
HTTP/1.1 404 Not Found
Content-Type: text/html
Cache-Control: public, max-age=3600
```

`sw.js` already had `Cache-Control: no-cache` and `Service-Worker-Allowed: /`, but asset and error responses lacked the inherited security headers because location-level `add_header` replaced them.
